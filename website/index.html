Deployment approach

Start with one site. Validate the workflow. Scale with confidence.

The first step is to confirm camera compatibility and network access, then validate actual telemetry before relying on the system operationally.

A cloud API is available; camera connectivity, alert delivery and site-specific compatibility must be tested with authorised equipment before production use.
